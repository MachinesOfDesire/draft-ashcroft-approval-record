Abstract

A standing authorization grant is an artifact that outlives the event that produced it. Existing authentication-strength vocabulary (acr/amr) describes authentication events and travels on tokens. Nothing carries a record of how a standing grant's approval was performed to the party verifying the grant, possibly days later and with no human present. This document defines an approval-act record: evidence of the approval ceremony, bound to the exact grant issuance approved, and carried in-band with the grant it authorizes. It defines one initial evidence type (WebAuthn assertions over a hash of the canonical grant), states precisely which of the record's claims a verifier can recompute, which rest on vendor attestation, and which remain attested by the operator, and provides a worked example with a failure matrix.
